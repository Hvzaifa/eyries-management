# Reference

The distinction matters: a rule in [`../business-rules.md`](../business-rules.md)
must be followed; a note here describes how something behaves in practice and may
go out of date as the system or its inputs change. Nothing here overrides
`business-rules.md`, `data-model.md` or `decisions.md`.
